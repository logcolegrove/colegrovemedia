03 - FAQ

Common Questions

Lottie is an animation format that exports as a small JSON file rendered as SVG in the browser. Much smaller than a GIF or video, infinitely scalable, smooth on mobile. The format Apple, Google, and Airbnb all use for their UI animations.

Lottie drops in with a single script tag and a JSON file. Most modern site builders (Webflow, Framer) support it natively. I'll provide an implementation guide; for custom builds, install support is available as an add-on.

Typically 30-200KB. Compare to a 1-5MB GIF or 3-15MB video for the same animation. Lottie wins on performance every time.

Yes. Lottie is cross-platform. Same JSON file renders in iOS, Android, and the web with native players.
